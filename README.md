# Home Deluxe Trading Bot

Безопасная версия проекта подключается к Binance Spot Testnet, проверяет тестовый
API-ключ и круглосуточно следит за всеми активными Binance Spot-парами к USDT
через публичный WebSocket-поток Binance с обновлением примерно раз в секунду.
Пары с низким суточным оборотом
отсеиваются. Бот начинает оценку зарождающегося движения при росте от 0,5% за 5 минут и отмечает
движение от 3% как сильный сигнал. Реальные сделки эта версия не совершает.
Все сигналы сохраняются и анализируются, но по умолчанию Telegram работает в
тихом режиме: присылает только входы, выходы, баланс, отчёты и ошибки.

Каждый сигнал автоматически проверяется через 15, 30 и 60 минут. Суточный отчёт
показывает долю положительных исходов и средний результат после ориентировочных
торговых издержек, а ИИ формирует краткий вывод по накопленной статистике.

Встроенный режим виртуальных сделок использует публичные цены Binance, но не
отправляет заявки на биржу. Стартовый виртуальный банк — 200 USDT. По умолчанию
бот динамически распределяет весь доступный банк между четырьмя местами для позиций,
а после входа отдельно следит за каждой открытой позицией по лучшей доступной
цене продажи (best bid) из потока стакана в реальном времени.
фиксирует 50% позиции при росте на 0,7%, оставшиеся 50% — при росте на 1%,
ограничивает убыток уровнем 0,5% и после первой фиксации не опускает защиту
остатка ниже уровня +0,7%. Принудительный выход по времени
отключён: позиция закрывается по движению цены. После каждого входа и выхода
Telegram показывает стартовый капитал, текущий баланс, общий результат,
свободные средства и сумму в открытых позициях.

Перед ИИ-оценкой бот также загружает минутные свечи и передаёт объём последних
пяти минут, его отношение к среднему пятиминутному объёму предыдущих двадцати
минут, количество сделок, долю покупательского объёма, спред и перевес заявок
в первых двадцати уровнях стакана.

До покупки действует фильтр исполнимости: бот не открывает позицию при спреде
выше 0,1% или минимальном шаге цены выше 0,1% текущей цены. Сигнал сохраняется
как отклонённый, но не расходует запрос к ИИ и не создаёт виртуальную сделку.

Дополнительно бот анализирует последние 3–4 завершённых похожих импульса именно
этой монеты за сутки по сохранённым ценам. Для каждого случая проверяется путь
следующих 15 минут: максимум, просадка и достижение +0,7%/+1% раньше стопа −0,5%.
До накопления трёх случаев вход запрещён. После накопления вход разрешается,
только если не менее двух третей случаев достигли первой цели и два последних
случая не завершились стопом до неё. Эта история передаётся ИИ вместе с текущим
объёмом и стаканом.

Суточный разбор виртуальной торговли считает максимальный рост и просадку после
каждого входа, долю отданного движения, profit factor и параллельно пересчитывает
те же сигналы для полного выхода на +0,7%, +1% и +1,5%. Эти данные передаются ИИ для
предварительного вывода; стратегия автоматически не переписывается по малой
выборке.

Отчёт отдельно группирует сделки по росту монеты в момент входа: 1–1,49%,
1,5–1,99%, 2–2,99% и от 3%. Для каждой группы показываются количество сделок,
доля прибыльных, общий результат и срабатывание целей +0,7%/+1%. Следом Telegram
присылает список монет с точкой входа, ИИ-оценкой, максимумом после покупки,
результатом и причиной выхода.

Через 15 минут после входа бот проверяет последние 5 минут. Если нового максимума
не было, позиция закрывается только с положительным результатом после учёта
расходов. Правило действует и для остатка после первой фиксации. Отрицательная
позиция по времени не закрывается: для неё действует стоп-лосс.

При разрыве WebSocket-соединения бот автоматически переподключается и временно
возвращается к REST-проверке. Снимки цен для аудита сохраняются раз в 15 секунд,
поэтому высокая частота потока не раздувает базу данных.

## Безопасность

- Никогда не отправляйте API secret или Telegram token в чат.
- Храните секреты только в локальном `.env` на сервере.
- Для реального Binance API никогда не включайте вывод средств.
- Пока `BINANCE_BASE_URL` указывает на `testnet.binance.vision`, реальные деньги не используются.

## Запуск

1. Скопируйте `.env.example` в `.env`.
2. Вставьте тестовые Binance API key/secret и Telegram bot token.
3. Установите зависимости: `python -m pip install -r requirements.txt`.
4. Запустите: `python -m bot.main`.

По умолчанию включено динамическое сканирование всех активных Spot-пар к USDT.
Режим, минимальный оборот, ранний и сильный пороги, частота проверки и пауза между
повторными уведомлениями настраиваются переменными `SCAN_ALL_USDT`,
`MIN_QUOTE_VOLUME_USDT`, `EARLY_THRESHOLD_PERCENT`, `PUMP_THRESHOLD_PERCENT`,
`POLL_INTERVAL_SECONDS`, `ALERT_COOLDOWN_SECONDS` и
`TELEGRAM_SIGNAL_ALERTS_ENABLED`.

Если `TELEGRAM_CHAT_ID` пуст, программа возьмёт chat ID из последнего сообщения,
отправленного боту, и покажет его в терминале.
